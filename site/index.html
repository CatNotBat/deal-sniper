Facebook Marketplace × Claude

Spot the underpriced listing before anyone else.

Deal Sniper reads the Marketplace search you already have open, asks Claude what each item really sells for used, checks the best candidates with live web search, and ranks what is worth a message.

See a sample run Install the bookmarklet

How it works

No extension, no server, no account. A bookmark, a static page, and your own Anthropic API key.

  1. Scrape what you see

    On a Marketplace search, click the bookmark. It scrolls the results and reads each listing card: title, price, location, photo.

  2. Estimate the market

    Claude Haiku identifies the exact model in any language and estimates its used price range in your local currency.

  3. Verify the best

    The strongest candidates go to Claude Sonnet with web search, which checks real second-hand prices and links its sources.

Install

Drag the button to your bookmarks bar. Then open a Facebook Marketplace search and click it.

Deal Sniper

No bookmarks bar? Press Ctrl+Shift+B (⌘+Shift+B on a Mac). On mobile, bookmarklets are awkward; use a desktop browser.

Your key, your browser

The results page talks to the Claude API directly from your browser. There is no backend to trust.

Where the key lives
In this browser's storage for this site only, or just for the tab if you untick "remember". It is sent only to api.anthropic.com.
What it costs
About $0.20 for a typical scan: screening is about a cent, each web-search check about $0.07. You see an estimate before starting and the running cost as it goes.
What leaves Facebook
Listing text and prices travel in the page URL fragment, which browsers never send to a server.
Use a dedicated key
Create a separate key with a low spend limit in the Anthropic Console, so you can revoke it at any time.
Deal Sniper is an independent hobby project, not affiliated with Meta or Anthropic. Automated access may conflict with Facebook's terms; use it on your own searches, at your own risk. Source on GitHub
